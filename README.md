# 🐧企鹅·命令面板

一款 **SillyTavern（酒馆）+ 酒馆助手（JS-Slash-Runner）** 的插件脚本。

把酒馆自带的 Slash 命令（`/hide`、`/sendas`、`/bubble` 等）做成**带功能注释的可视化按钮**，点击即执行，不用手打、不用背命令，纯奶龙也能丝滑操作。

> ⚠️ 本脚本代码 **100% 由 AI 编写**（vibe coding 产物），作者仅负责提出需求与测试反馈。

---

## ✨ 功能一览

### 🚀 生成与发言
| 命令 | 功能 |
| --- | --- |
| `/trigger` | 立即触发一次 AI 回复 |
| `/continue` | 让 AI 从最后一条消息继续往下写 |
| `/impersonate` | AI 以你的口吻代写一条发言 |
| `/swipe` | 给最后的 AI 回复换一个新版本（等同左划） |
| `/send` | 以你的身份追加一条消息（不触发回复） |
| `/sendas` | 以指定角色的身份追加消息（只需填角色名和内容，前缀自动拼装） |
| `/sys` | 插入一条系统旁白楼层 |

### 🗂 楼层管理
| 命令 | 功能 |
| --- | --- |
| `/hide` `/unhide` | 隐藏 / 取消隐藏楼层（隐藏后不发送给 AI） |
| `/del` | 删除指定楼层（⚠️ 危险操作，不可撤回！） |
| `/cut` | 剪切指定楼层（⚠️ 危险操作！） |

### 💬 聊天管理
| 命令 | 功能 |
| --- | --- |
| `/newchat` | 新开一个空白聊天 |
| `/getchatname` | 查看当前聊天文件名 |

### 🔧 其他
| 命令 | 功能 |
| --- | --- |
| `/echo` | 弹出一条提示文字 |
| `/help` | 打开酒馆自带命令帮助 |

### 🖥 界面切换
| 命令 | 功能 |
| --- | --- |
| `/bubble` `/flat` `/single` | 气泡 / 扁平 / 单行消息模式 |
| `/panels` | 显示 / 隐藏 UI 面板 |
| `/reload-page` | 刷新酒馆页面（未发送的输入会丢失！） |

### 📝 其他能力
- **手动命令运行**：面板底部可输入任意命令执行，覆盖面板没收录的命令
- **关键字筛选**：顶部搜索框快速定位命令
- **文本格式化**：填入文本一键生成 `*斜体*`、`**粗体**`、`~~删除线~~`、`> 引用`、`# 标题`、`[超链接](网址)`、`![图像](网址)`、代码块等格式，输出到酒馆输入框，不直接发送
- **状态反馈**：每一步执行都有成功/失败提示与耗时显示
- 需要参数的命令自带输入框和格式提示；`/sendas` 走酒馆助手官方接口直写消息，杜绝"发出去却是空楼层"的问题

## 📦 安装方法

1. 确保已安装 **酒馆助手（JS-Slash-Runner）** 扩展
2. 打开 酒馆助手 → 脚本库 → **新建脚本**
3. 把 `命令面板.js` 的全部内容粘贴进「脚本内容」，脚本名称随便填
4. 保存并**启用脚本**（⚠️ 新导入的脚本默认是关闭的，记得手动打开）
5. 酒馆助手按钮栏会出现「🐧企鹅·命令面板」按钮，点击即可打开面板

> 面板可拖动，右上角 ✕ 关闭。

## 📖 使用示例

- 想让某楼不被 AI 看到？→ 找到 `/hide`，楼号留空（默认最后一楼）点一下
- 想让 NPC 说话？→ `/sendas` 填角色名 + 消息内容，点按钮
- 想发一条带格式的消息？→ 在「文本格式化」里输入文本，点「粗体」，格式化结果自动进输入框

## ❓ 常见问题

**Q：点了按钮没反应？**
A：确认脚本已启用；按 F12 打开控制台，把红色报错截图反馈给作者。

**Q：命令执行了但好像没效果？**
A：部分命令（如 `/del`）执行后酒馆不会有弹窗提示，可看面板底部状态栏的返回值确认。
