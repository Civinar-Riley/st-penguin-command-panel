## 📖 项目简介

- **一句话**：把酒馆自带的 Slash 命令（`/hide`、`/sendas`、`/bubble` 等）做成带中文说明的按钮，点一下就执行，不用手打、不用背命令。
- **与手打完全等效**：所有命令都通过酒馆助手官方接口 `triggerSlash()` 执行，等价于在输入框里手打命令，不魔改酒馆本体。
- **零依赖、无构建**：整个面板是单文件脚本，不引入任何第三方库，不需要 npm，也没有打包步骤。
- **危险操作有护栏**：`/del`、`/cut` 点击后弹出二次确认，确认框不回「确定」就不执行；参数含空格或换行时自动加引号转义，避免正文被命令行管道截断。
- **手机与桌面共用一套面板**：窄屏自动切成贴边全宽布局，按钮点击目标加大到 40px，输入框字号提到 16px 以防 iOS 聚焦时整页放大，软键盘弹出时面板按可视视口收缩、不会遮住正在输入的地方。
- **格式化只写入不发送**：文本格式化的结果输出到酒馆输入框，由你确认后再自行发送。
- **可重复导入**：脚本启动时按固定 id 清理旧入口按钮、旧面板与旧样式表，重复导入不会叠出多层面板。
- **下载链接不会过期**：脚本包文件名不带版本号，`main` 上的那一份始终是最新版；版本号由 git tag 标记，面板标题栏与状态栏也会显示当前版本，方便确认自己装的是哪一版。
- ⚠️ 本脚本**代码全部由 AI 编写**（vibe coding 产物），作者仅负责提出需求与测试反馈。

## ✨ 功能特性

### 入口一 · 面板命令按钮

共 21 条命令、5 个分组，与面板中的分组一致。「参数」列即面板输入框里的提示文字。

**🚀 生成与发言**

| 命令 | 参数 | 说明 |
| :--- | :--- | :--- |
| ⚡ `/trigger` | 无需参数 | 立即触发一次 AI 回复 |
| ➡️ `/continue` | 无需参数 | 让 AI 从最后一条消息继续往下写 |
| 🎭 `/impersonate` | 无需参数 | AI 以你的口吻代写一条发言，写入输入框供你确认 |
| 🔄 `/swipe` | 补充提示词（可留空） | 给最后的 AI 回复换一个新版本，等同左划 |
| ✉️ `/send` | 消息内容 | 以你的身份追加一条消息，不会触发回复 |
| 🎬 `/sendas` | 角色名 + 消息内容（两个输入框） | 以指定角色的身份追加一条消息，走直写接口而非命令管道 |
| 📢 `/sys` | 旁白内容 | 插入一条系统旁白楼层，即 AI 能看到的舞台指示 |

**🗂 楼层管理**

| 命令 | 参数 | 说明 |
| :--- | :--- | :--- |
| 🙈 `/hide` | 楼号（留空＝最后一楼） | 隐藏楼层：不发送给 AI，但界面上仍然可见 |
| 👁️ `/unhide` | 楼号（留空＝最后一楼） | 取消隐藏，恢复把该楼层发给 AI |
| 🗑️ `/del` | 楼层数 | 删除指定楼层层数（危险操作，不可撤回，有二次确认） |
| ✂️ `/cut` | 楼号 | 剪切掉指定楼层并使其后楼层上移（危险操作，有二次确认） |
| 🎯 `/chat-jump` | 消息索引（从 0 开始） | 将聊天视图滚动到指定的消息索引 |

**💬 聊天管理**

| :--- | :--- | :--- |

| 🏷️ `/getchatname` | 无需参数 | 查看当前聊天的文件名，结果显示在状态栏 |

## 📦 安装

**环境要求**

| 依赖 | 说明 |
| :--- | :--- |
| SillyTavern（酒馆） | 本体，仓库未声明最低版本要求；桌面端与移动端皆可 |
| 酒馆助手（JS-Slash-Runner） | **必需**，面板依赖它提供的 `triggerSlash()`、`createChatMessages()`、脚本按钮与事件接口 |
| Node.js / 构建工具 | **不需要**，脚本为单文件、零第三方依赖 |

**导入步骤**

1. **取得脚本包**：下载 [`酒馆助手脚本-企鹅-酒馆原生命令面板.json`](./酒馆助手脚本-企鹅-酒馆原生命令面板.json)——文件名不带版本号，这个链接始终指向最新版；也可以下载 `command_panel.js` 后新建脚本粘贴全文。
2. **导入**：打开 酒馆助手 → 脚本库 → 导入 → 选择刚下载的 JSON 文件。
3. **启用**：保存后在脚本库中把该脚本切换为**启用**——新导入的脚本默认是关闭的。
4. **确认生效**：酒馆助手按钮栏出现「🐧企鹅·命令面板」按钮，点击后面板展开、状态栏显示「待命中」，即安装成功。

**配置一览**

| 项 | 位置 | 默认值 / 说明 |
| :--- | :--- | :--- |
| 脚本按钮名 | `command_panel.js` 的 `SCRIPT_BUTTON_NAME` | `🐧企鹅·命令面板` |
| 当前版本号 | `command_panel.js` 的 `VERSION` 常量 | `v1.4`，面板标题栏与状态栏都会显示 |
| 命令清单 | `command_panel.js` 的 `COMMANDS` 数组 | 21 条，按 5 个分组渲染 |
| 格式化按钮 | `command_panel.js` 的 `FORMATS` 数组 | 13 种格式 |
| 面板初始位置 | `command_panel.js` 内联样式 `#cmdpanel-panel` | 右上角（距顶 64px、距右 24px），宽度上限 480px；窄屏下改为贴边全宽 |
| 窄屏断点 | `command_panel.js` 内联样式媒体查询 | 600px，面板切贴边布局并加大点击目标 |
| 接口等待上限 | `command_panel.js` 启动轮询 | 15 秒，每 500ms 探测一次 |
| 密钥 / 外部依赖 | — | 无。不读取 API Key，也不发起任何外部网络请求 |

> ⚠️ **最容易翻车的是第 3 步**：脚本导入后默认关闭，不手动启用则按钮永远不出现。
> ⚠️ **只保留一个版本**：导入新版后请把旧脚本停用或删除，同时启用多份会让同一个面板被初始化多次。
> ⚠️ **`/del`、`/cut` 不可撤回，`/reload-page` 会清空未发送的输入**：前两者会弹二次确认，确认前请看清命令与参数。

## 🚀 使用指南

| 场景 | 操作 |
| :--- | :--- |
| **让 AI 继续往下写** | 打开面板 → 点 `/continue` |
| **让某一楼不被 AI 看到** | 点 `/hide`，楼号留空即最后一楼；填楼号则隐藏指定楼层 |
| **让某个角色说一句话** | 在 `/sendas` 的角色名框与消息内容框分别填写 → 点 `/sendas` |
| **删掉写崩的楼层** | `/del` 填要删除的楼层数 → 点按钮 → 二次确认弹窗点确定 |
| **发一条带格式的消息** | 在「文本格式化」区填入文本 → 点「粗体」等按钮 → 结果进入酒馆输入框，确认后自行发送 |
| **运行面板没收录的命令** | 在面板底部输入框输入命令（例：`/hide 3`）→ 按 Enter 运行 |
| **快速定位命令** | 在顶部搜索框输入关键字，同时匹配命令名与说明文字 |
| **参数需要换行** | 在参数框内按 Shift+Enter 换行，直接按 Enter 等同点击执行 |
| **在手机上操作** | 面板会自动铺满窄屏宽度并让开顶栏，点按钮即可；手动命令框与「运行」在窄屏下是上下两行 |

## 🚧 限制与已知问题

| 限制 | 原因 | 能否绕过 |
| :--- | :--- | :--- |
| 必须安装酒馆助手扩展 | 命令执行依赖它提供的 `triggerSlash()` 等接口 | ❌ 平台决定 |
| 只收录硬编码的 21 条命令 | `COMMANDS` 是静态数组，不读取酒馆现有的命令列表 | ✅ 用底部手动输入框运行其他命令 |
| 面板位置不持久化 | 未做本地存储，刷新后回到默认位置；窄屏下是固定的贴边位置 | ❌ 当前版本无此功能 |
| 同时启用多个版本会重复初始化 | 每份脚本都会各自注册按钮监听与视口监听 | ✅ 只保留一份启用的脚本 |
| v1.3 包的二次确认不生效 | 该包的危险标记漏加在带参渲染分支，`/del`、`/cut` 会**直接执行** | ⚠️ 只作历史留存，请用最新包 |
| v1.0 包缺少参数转义与二次确认 | 更早的版本，没有 `quoteArg()` 转义，也没有危险命令确认 | ⚠️ 只作历史留存，请用最新包 |
| 面板配色不跟随酒馆主题 | 注入的样式是固定深色配色，桌面与手机一致 | ❌ 需自行修改 CSS |
| 启动时环境未就绪会放弃加载 | 探测扩展接口超过 15 秒即退出，且只在控制台留下一行报错 | ✅ 启用扩展后刷新酒馆页面 |

## ❓ 常见问题

**Q：导入后按钮栏没有出现「🐧企鹅·命令面板」？**
A：新导入的脚本默认处于关闭状态，到 酒馆助手 → 脚本库 手动启用；仍未出现就刷新一次酒馆页面。

**Q：控制台报「未检测到酒馆助手接口」？**
A：脚本启动后会以 500ms 为间隔探测 `triggerSlash`、`appendInexistentScriptButtons`、`getButtonEvent`、`eventOn` 四个接口，累计 15 秒仍不齐就放弃加载。确认酒馆助手已启用，然后刷新页面。

**Q：点了按钮好像没反应？**
A：部分命令酒馆本身不弹提示（例如 `/del`），请看面板底部的状态栏：成功会显示命令名、耗时与返回值，失败会显示红色错误信息。若状态栏也没有动静，按 F12 查看控制台报错。

**Q：`/sendas` 发出去是空楼层？**
A：`/sendas` 不走命令行管道，而是改用酒馆助手的 `createChatMessages()` 直写消息。请确认导入的是 `...v1.4.json`（v1.0 包没有这个处理）。

**Q：参数里有空格或换行会被截断？**
A：v1.3 起参数会先经过 `quoteArg()` 自动加引号并转义（含空格、双引号、竖线时触发）。v1.0 包没有这个处理，建议换成 v1.4。

**Q：`/del` 和 `/cut` 为什么以前直接执行、现在会弹确认框？**
A：v1.3 就写了二次确认，但危险标记只加在「无参数命令」那一支，而这两条命令都带参数、渲染走的是另一支，确认框实际上从未弹出；v1.4 修复了这个问题。这也是为什么旧包执行 `/del` 不会问你。

**Q：手机上能用吗？**
A：可以。窄屏（≤600px）会自动切换成贴边全宽布局，按钮点击目标加大到 40px 以上，输入框字号 16px 以避免 iOS 聚焦时整页放大；软键盘弹出时面板会按可视视口收缩，底部的手动命令框不会被键盘盖住。面板左上角与顶栏留了间距，下方保留酒馆输入区可见。

**Q：手机上拖不动面板？**
A：拖动优先使用 Pointer Events，若运行环境（部分 WebView）不支持，会自动退回鼠标与触摸事件，无需手动切换。窄屏下面板本身就是贴边全宽，通常不需要拖动。

**Q：面板颜色和酒馆主题不一样？**
A：面板注入酒馆主页面并自带固定深色配色（底色 `#171a21`、强调色 `#b8956a`），不跟随酒馆主题切换。

**Q：会读取我的 API Key 或联网吗？**
A：不会。脚本只操作页面 DOM 并调用酒馆助手接口，不含任何外部网络请求。

**Q：不装酒馆能先看看效果吗？**
A：可以。仓库 [`tests/`](./tests/README.md) 里有一个本地验证台，用桩函数冒充酒馆助手的接口，在浏览器里直接跑起面板并自检 22 项（布局、命令拼接、参数转义、二次确认、格式化输出等），还可以用 DevTools 把视口调成 412px 验证移动端布局。跑法见 [tests/README.md](./tests/README.md)。
